# CMC Vellore — Portfolio UI/UX Concept

A frontend-only conceptual redesign of the Christian Medical College Vellore homepage, built for portfolio presentation.

**Not an official CMC website.**

## Files

```
index.html         Homepage
appointment.html   Patient portal / book appointment
faq.html           FAQ page
style.css          All styles
script.js          Navbar, tabs, accordion, demo toasts
assets/images/     Logo & poster
videos/            landing.webm hero video
```

## Run locally

Open `index.html` in a browser, or use any static server:

```bash
npx serve .
# or
python3 -m http.server 8080
```

Then visit `http://localhost:8080`
